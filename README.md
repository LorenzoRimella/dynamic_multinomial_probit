# Online inference for dynamic categorical regression

The repository is organized as follows:
- R scripts in the main folder can be used to reproduce figures and tables from the paper, and specifically: filtering_tables.R reproduces Table 1 and filtering_traj.R reproduces figures S.1-S.2-S.3, repeated_EM.R reproduces Table 2 and Figure 2, expedia_inference.R reproduces Figure 3, Figure 4.
- the folder scripts contains all the main code that has been used to run the experiments
- the folder experiments contains the experiments run on the cluster to get the results in Section 6
- the folder data contains all the input-output data to reproduce experiments, table and figures
- the folder figures contains the figures used in the paper
